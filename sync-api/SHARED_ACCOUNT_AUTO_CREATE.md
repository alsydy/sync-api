# إلغاء الصناديق المشتركة (تحديث الآلية)

تم إلغاء الحسابات المشتركة نهائيًا، وأصبح لكل مستخدم صندوقان افتراضيان فقط:

- `template_key = 'main'` → الصندوق الرئيسي
- `template_key = 'transfer'` → تحويل بين الحسابات

## ما الذي تغير؟

- **تم إلغاء** الحساب المشترك العالمي `shared-main-account-v1`.
- الخادم الآن **يرفض** أي معاملة تشير إلى حساب مشترك.
- **إنشاء الصناديق الافتراضية** يتم على الخادم فقط عبر `ensureDefaultAccounts(userId)` (مع `UPSERT`).
- التطبيق يحصل على الصناديق عبر `POST /api/bootstrap` بعد أول تسجيل/دخول.

## السلوك الحالي

- أي `accountFirestoreId = 'shared-main-account-v1'` سيتم رفضه بخطأ واضح.
- لا يتم إنشاء أي صندوق افتراضي داخل التطبيق.
- الصناديق الافتراضية `is_shared = false` دائمًا.

## ملاحظة ترحيل

إن وُجدت معاملات قديمة تشير لحسابات مشتركة، تبقى تاريخيًا ولا يتم إنشاء معاملات جديدة عليها.

**الحالة**: ✅ تم تطبيق الآلية الجديدة بالكامل.
